# Sentinel: Seed Data

Everything is synthetic and generated by `seed/seed.py`, deterministic with seed **1337** (SD-07). `make seed` deletes the database and rebuilds all datasets in the order of section 8. Numbers and IDs in this file are verified by computation and are test fixtures (T-SD-01..03, T-BP-*, T-PS-*).

## 1. Customer DB and canaries (SD-01)

| Item | Specification |
| --- | --- |

## 8. Seed order (SD-07)

1. Delete DB. Create schema, triggers. Set clock to `2026-01-01T00:00:00.000Z`, advancing 1 s per ledger append during seeding.
